# 墨序：毛笔书写识别与用笔过程记录

MPU6050 固定在毛笔笔杆上，ESP32-S3 提供六轴和姿态数据，Python 保存与分析，网页展示实时过程、回放和单字模板匹配。首版词表为“一、十、口”，在真实纸上书写，暂不使用纸面摄像头。

当前为 v0.2 软件原型，文档整理日期：2026-11-08。**本 README 是毛笔项目入口**；旧运动记录技术方案已独立归档，不再作为当前软件实现说明。

## 2. 先演示，再接真实数据

### 实时窗口

1. 打开工作台，点击顶部 **“试播模拟实时流”**。
2. 查看最新六轴数值、笔杆姿态、不断增长的曲线；点击“演示大屏”用于投影。
3. 约 6 秒后自动结束，检查记录和匹配结果，再回放或定位事件。
4. 模拟数据标为 synthetic，与真实记录及模板隔离，只用于验证软件流程。

“先看看软件示例”提供已保存的合成示例；“试播模拟实时流”演示逐批到达的数据，两者入口不同。

### 真实采集

USB 波特率已确认 **115200**，实际数据行格式尚待硬件组提供。适配器预留逐行 JSON 和 CSV，目前不能宣称真实设备已经联通。

```powershell
D:/conda3_envs/zzss/python.exe -m pip install -r requirements-hardware.txt
D:/conda3_envs/zzss/python.exe serial_bridge.py --list
# COM5 仅为示例；按实际端口与固件输出格式修改。
D:/conda3_envs/zzss/python.exe serial_bridge.py --port COM5 --baud 115200 --format jsonl
```

串口桥运行后，网页点击“开始真实记录” → 等收到样本再落笔 → 写完整一个字 → 停稳并等数据更新 → “结束并分析”。没有发送端时，窗口保持等待，不会以模拟数据替代硬件。

网页约每 100 ms 增量刷新，设备仍建议按 100 Hz 保存。已到达 Python 的样本独立保存，页面断线后按游标补取。结束边界以服务器已保存样本为准，固件最终 seq 确认和批次可靠重传尚未实现。

### CSV 导入

已有文件可以直接导入，不必等待串口联调。必需列为 sample_us（微秒）、ax_g / ay_g / az_g（g）、gx_dps / gy_dps / gz_dps（°/s）。角度、序号和其他字段按 [硬件数据接口约定](./硬件数据接口约定.md) 提供。

低频或不连续记录可以保存和回放，但不能据此建立有效识别模板。历史约 3 Hz 摇摆文件不代表当前固件采样率。

## 3. 单字识别如何推进

当前使用六轴序列与个人模板进行 DTW 匹配，没有使用已验证的中文毛笔预训练权重。

1. 固定书写者、传感器安装方向和安装版本，按完整单字分段采集“一、十、口”。
2. 建议每字采集 10 条示范模板、5 条验证、10 条独立测试；三类数据独立录制。
3. 导入用途选“示范模板”，质量通过后加入模板库。
4. 最低每字 3 条模板、2 条独立验证后可联调阈值校准；这是最低联调数量，不代表统计效果可靠。
5. 以“练习记录”录入新字，识别不读取答案；未校准时仅展示候选。
6. 用留出的测试集评估准确率、Macro-F1、混淆矩阵、延迟和统计特征基线。

模板按书写者、安装版本与真实/合成来源隔离。质量要求、预处理和评估细节见 [软件使用说明](./软件使用说明.md)。

## 6. 代码与本地数据

```text
run.py                       启动入口，默认本机 8765
brush_backend/app.py         HTTP 接口与静态页面
brush_backend/schemas.py     数据契约
brush_backend/storage.py     SQLite 与批量事务
brush_backend/service.py     CSV、模板、识别、评估、规则问答
brush_backend/algorithms.py  质量、预处理、DTW 和基础指标
brush_backend/live.py        实时会话、模拟流与游标补取
serial_bridge.py             USB 串口转批量 HTTP
web/                         页面、曲线、笔杆姿态和回放
tests/                       核心与实时接口测试
data/                        自动生成的本地记录、原始 CSV 和模板状态
```

安装开发依赖后测试：

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
```

此前 16 项自动测试通过，覆盖采样质量、模板隔离、DTW、鉴权、增量补取、模拟结束与串口解析。它们证明软件流程，不代表真实毛笔识别准确率。

默认仅监听本机。局域网使用需先设置至少 16 位 BRUSH_API_TOKEN，再运行 python run.py --host 0.0.0.0；页面和串口桥使用相同令牌。不要将 .env 或 data/ 提交版本库。
