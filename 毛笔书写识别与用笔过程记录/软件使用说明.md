# 墨序：毛笔书写工作台

这是“毛笔＋MPU6050”的本地 Python 原型。v0.2 新增实时书写窗口，同时保留 CSV 导入。当前桌面目录为“毛笔书写识别与用笔过程记录”，原执行计划保留。

## 1. 启动

双击同目录的 **启动毛笔工作台.cmd**，保持命令窗口打开。也可以在 PowerShell 运行：

    cd "C:\Users\zzs\Desktop\毛笔书写识别与用笔过程记录"
    D:/conda3_envs/zzss/python.exe run.py

- 工作台：http://127.0.0.1:8765/
- Swagger 接口：http://127.0.0.1:8765/docs
- 健康检查：http://127.0.0.1:8765/api/v1/health

课程 Python 环境已包含本版运行依赖。换环境时安装：

    python -m pip install -r requirements.txt
    python run.py

不需要 Node、npm、数据库服务或外部模型账号。原始文件、元数据和模板状态存放在 data/，默认不提交 Git。

## 2. 和硬件组并行做什么

你负责 Python 接口、数据管理、模板算法、页面和报告；硬件组负责采样、姿态与距离算法。USB 串口已确认 115200，实际行格式待提供；串口桥预留 JSONL / 带表头 CSV。

**先看现场展示效果：打开工作台，点击顶部“试播模拟实时流”，再点“演示大屏”。** 模拟信号逐批发送约 6 秒，可观察六轴数字、姿态、曲线增长，结束后自动检查和匹配。它不是现场真实书写。详见 [实时演示与串口接入](./实时演示与串口接入.md)。

1. 启动后点击“先看看软件示例”：检查候选字、姿态、曲线、回放和规则问答。合成示例不是训练效果证明。
2. 将 [硬件数据接口约定](./硬件数据接口约定.md) 发给硬件组，确认列名、单位、时间戳和序号语义。
3. 导入一条真实 CSV：先看质量检查。以前约 3 Hz 的摇摆数据可以查看和回放，但不能用于识别。
4. 固定同一书写者和安装，采“一、十、口”；建议每字 10 条模板、5 条验证、10 条测试。
5. 导入时选择用途和标签。示范模板质量通过后，点击“加入模板库”。
6. 每字至少 3 条模板、2 条独立验证记录后，在“示范与验证”中校准。最低数量只为联调，建议按计划采集。
7. 以“练习记录”导入新字，再点击“匹配示范”。识别不读取答案；校准前只显示候选。
8. 导入独立测试记录，评估准确率、Macro-F1、最近类别中心基线和混淆矩阵。

模板、验证和测试必须独立录制。软件拒绝相同六轴数据重复导入，但这项检查不能替代正确的数据划分。多文件导入共用当前用途和标签。

## 3. 已实现与待接入

| 模块 | 当前行为 |
|---|---|
| CSV | UTF-8、GB18030、带 BOM 的 UTF-16；逗号、分号和制表符；保留可选列 |
| 保存 | SQLite 保存全部解析样本和元数据；原始 CSV 另存 |
| 质量 | 检查频率、时间、序号、重启、超过 100 ms 缺口与 clipped |
| DTW | 六轴、模板集归一化、低通、50 Hz 处理网格、最长 200 点、路径长度归一化 |
| 阈值 | 独立已知字验证集校准；模板改变后失效 |
| 隔离 | 按书写者、安装和真实/合成来源匹配 |
| 页面 | 实时采集状态、最新六轴、姿态与增量曲线、演示大屏，以及回放、事件定位、导出 |
| 评估 | 留出测试、含拒识的准确率、Macro-F1、混淆矩阵、P95 和统计特征基线 |
| 解读 | 离线规则问答，绑定当前记录，尚未调用大模型 |
| 实时接入 | 会话开始/恢复、批量保存、游标增量拉取、结束后自动检查和匹配；USB 桥预留 115200 |

**真实毛笔识别准确率尚未验证。** 合成模板不能参与真实记录识别。合成数据的测试只能证明软件流程。

待验证：真实固件行格式与 USB 串口联调、真实书写识别率。暂未实现蓝牙适配、外部大模型调用、纸面字形识别、压力/笔锋/书法等级判断。距离只展示硬件传入的 distance_mm，本版不重算距离算法。

## 4. 页面与代码入口

- 选中的记录决定“示范与验证”的当前分组，顶部显示真实或合成来源。
- “其他”标签用于词表外验证/测试负样本；模板只接受一、十、口。
- 有角度字段才显示姿态；三维笔杆按设备角度示意，实际笔杆安装方向仍需标定。
- 曲线在超过 100 ms 缺口处断开；最大已保存角速度不保证是连续过程的真实峰值。
- 系统参考字形不是实际墨迹。模板移出后可重新加入；改变模板后需重新校准、匹配。

    run.py                         启动入口，默认只监听本机
    brush_backend/app.py           FastAPI 路由与静态页面
    brush_backend/schemas.py       字段契约
    brush_backend/storage.py       SQLite 与批量事务
    brush_backend/service.py       导入、模板、识别、校准、评估、规则解读
    brush_backend/algorithms.py    质量、预处理、DTW、基础指标
    brush_backend/live.py          实时会话、增量拉取与模拟流
    serial_bridge.py               USB 串口转批量 HTTP；115200，行格式待确认
    web/index.html                 页面
    web/style.css                  响应式样式
    web/app.js                     交互、曲线和姿态回放
    tests/test_workbench.py        核心逻辑与接口测试
    data/                          自动创建的运行数据

这是独立原型，没有修改滑雪知识库后端。接口沿用 code/msg/data，便于后续整合。

## 5. 测试

    python -m pip install -r requirements-dev.txt
    python -m pytest tests -q

覆盖稀疏数据拒识、时间/序号异常、重复数据、模板与测试隔离、合成数据隔离、角度环绕、距离来源、鉴权、批量保存、留出评估和当前记录引用。

软件测试通过不代表真实识别通过。真实验收仍需独立采集、固定安装和报告样本数。

## 6. 后续接大模型和实时数据

当前 /chat 返回 mode=rules，页面标为离线规则。接大模型时保留 report() 作为事实输入，新增供应商适配层，问题和结构化报告一起传入，保留记录 ID、指标和时间点来源。API key 由后端配置读取，不进入前端、CSV、源码和日志。

实时窗口每次按游标增量获取约 100 ms 一次，不代表设备仅以 10 Hz 采样。固件可直接 HTTP 上报，或由 serial_bridge.py 转发 USB 串口；具体行格式尚待硬件组确认。保存与页面刷新独立，断线后从游标补齐。详见硬件约定和实时接入说明。

默认只监听 127.0.0.1。需要受控局域网时，在 .env 设置至少 16 位的 BRUSH_API_TOKEN：

    python run.py --host 0.0.0.0

页面设置和上报脚本使用同一令牌，HTTP 头为 Authorization: Bearer <令牌>。不要把令牌提交版本库。互联网部署需要另外设计用户、权限和运维。
